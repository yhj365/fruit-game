项目:欢乐水果机，使用 nextjs+ts+taiwindcss+pgsql+drizzle 作为技术栈。用户注册，免费获取 100 积分。登录后界面如图。并且需要有后台管理系统管理用户，用户的积分修改、重置密码等功能。图片素材使用上传图片内根据位置自动截图使用或自动生成相对应的图片素材，放在/images 目录下。详细需求文档如下，并且需要将需求文档创建为独立的 md 文件：界面由 24 个方格拼接成一个正方形，每个方格中都有一个目标（多个不同的图形，通常为水果），且每个方格下都有一个小灯。玩家投入游戏币后，选择希望押注的目标，当玩家按下开始键后，小灯开始绕着正方形中每个格子转，当小灯停下来时，如果停在玩家押注的目标上时，则玩家可赢取相应的游戏币。
欢乐水果机特殊规则:游戏中设置了多个奖励，玩家触发了之后将会得到奖励。每个奖励的表现形式也各不相同。玩家点击某个押注物品则在该物品上下注。点击开始则游戏开始，如果没有下注则不能开始游戏。游戏中的物品有八中，分别为：苹果、西瓜、木瓜、橙子、铃铛、77、双星、BAR。
