# 欢乐水果机 UI/UX 设计规范

## 项目认知

这是一个复刻经典街机水果跑灯的小项目。普通玩家先注册或登录，再选择八种图案下注并启动跑灯；管理员在单独的后台查看用户。核心对象是账户积分、下注积分、停灯结果和待收取奖金，四者必须分开显示。

## 游戏页视觉依据

- 以 `design/shuiguo.png` 为唯一主要视觉参考。截图为 603×643，左右和底部有裁切；未知部分按可见材料延展，不编造文字或数据。
- 主盘为 7×7 外圈 24 格，中央 5×5 蓝色纹样舞台。格子沿外框顺时针编号，从左上角为 0。
- 黑色金属纹理机框、细银边、金色格框、饱和红黄绿蓝图案、蓝色数码下注条、红色中央数码屏和左侧历史灯列共同构成机台识别性。
- 保留图案上的 ×2、BAR ×25 / ×50 等逐格标注。下注键显示类别的常规倍率；逐格赔率优先。
- 参考截图由原始图案裁取进入页面；动态状态以真实文本和控件覆盖对应区域，避免把静态截图当成无法操作的界面。

## 产品与交互

- 主语言为简体中文。技术术语、实现说明、数据库状态不放在玩家主界面。
- 首要任务是下注 → 开始 → 识别结果 → 收分或猜大小。错误提示靠近动作区，说明下一步。
- 空历史记录使用暗灯占位，不能伪装成真实中奖记录。
- 开始、收分、猜大小、清空下注按主次分明；待收取奖金和账户余额分别标注。
- 窄屏优先完整展示 24 格盘面，下注项可以横向浏览，开始键必须易于到达。
- 动画与动效只服务于跑灯、激活和按钮反馈；尊重系统减少动态效果设置。

## 技术基础和验收

- 保持 Next.js App Router、React、Tailwind CSS，游戏机专属 CSS 放在 `app/globals.css`，盘面数据在 `lib/gameConfig.ts`。
- 桌面按原图宽度检查，手机至少检查 390px 宽度；确认 24 格顺序、历史列、下注可达性、提示和结果状态。
- 修改盘面配置时同步更新 README 的逐格赔率表。

## 已知边界

当前游戏在浏览器端运行，刷新会重置游戏积分；数据库账户积分与游戏结果尚未联动。红/蓝连中和其他组合奖未实现，不能在游戏页表现为可用功能。
