# 前端实现约定

## 必须满足

- 玩家页面仅显示真实状态和可操作动作；不显示默认管理员凭据、技术堆栈或未经实现的奖型。
- 下注、余额、待收取奖金分别显示；开奖时禁用会改变下注的控件。
- 未下注、余额不足、网络/服务错误需给出中文说明和下一步。
- 24 个灯格按 `lib/gameConfig.ts` 的 `row`、`column`、`index` 顺时针排列；视觉顺序和结算顺序一致。
- 控件使用语义按钮和可读名称；色彩之外还要以文字或明暗说明选中与禁用状态。
- 手机端保持盘面完整，不将八个下注按钮压成不可点击的窄列。

## 页面模式

| 页面 | 模式 |
|---|---|
| `/game` | 机框、历史灯、跑灯盘、数码条、下注键、结算动作。 |
| `/auth/login`、`/auth/register` | 简洁单栏表单，错误直接关联当前操作。 |
| `/admin` | 用户数据表，不在表格中直接暴露凭据。 |

## 页面验证

- 桌面和 390px 手机截图均可读。
- 下注 +1/−1、清空、开始、结果、收分与猜大小有反馈。
- TypeScript 和生产构建通过。
- 规则文档明确区分当前实现与待实现玩法。
