# 游戏页简报

## 用户与主要任务

玩家从登录/注册进入游戏页，先查看余额并选择图案下注，再按“开始”。跑灯结束后，玩家根据结果收分、猜大小或重押。

## 视觉布局

设计图 `design/shuiguo.png` 的 7×7 外框、中央蓝色舞台、左侧历史灯列、蓝色 LED 下注条和八个下注键为主结构。桌面以原图约 603px 的机台宽度居中；手机等比缩小棋盘，下注按钮横向滚动。

## 信息优先级

1. 盘面当前亮灯位置和中央状态。
2. 各图案下注量、倍率和开始/收分操作。
3. 账户余额、待收取奖金和历史结果。

## 恢复与边界

- 未下注：提示先选择图案。
- 余额不足：提示减少下注。
- 开奖中：禁用下注变更和再次开始。
- 浏览器刷新：游戏局重置，当前尚未持久化。
- 后台功能、数据库连接细节和未实现的奖型留在 README，不占据玩家界面。

## 验证

- 桌面与 390px 截图对照设计图。
- 下注和开始后确认数码条、跑灯、余额和历史变化。
- 校验 24 格是外圈而不是填满 6×4 的矩阵。
